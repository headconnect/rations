# Rations 2.2.2

- Fixed the missing **Weekly · Fable** usage row. Anthropic can report valid
  Fable usage with `is_active: false`, even while Claude's own usage page shows
  the allowance. Rations now displays that reported usage, including 0%, instead
  of hiding the row.
- When multiple Fable records are returned, Rations still prefers an active
  record. Fable remains in the popover only.

No account or settings changes are required.
