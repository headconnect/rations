# Rations 2.3.0

- New, off by default: **Usage Hub**. Rations can serve your signed-in Claude
  and Codex accounts' usage to T3 Code, which reads it as a CLIProxyAPI hub.
  Turn it on in Settings, then in T3 Code add a CLIProxyAPI hub with the URL
  (`http://127.0.0.1:8318` unless you change the port) and the management key
  shown there. The key is generated for you and kept in the keychain; you can
  replace it with your own.
- The hub listens on 127.0.0.1 only and answers from the usage Rations has
  already fetched, so it adds no requests to Anthropic or OpenAI and never
  hands out tokens. It refuses every other request a real CLIProxyAPI hub would
  forward, including Codex reset credits. Copilot is not served; T3 Code's hub
  support covers Claude and Codex only.

Existing accounts and settings are unchanged.
